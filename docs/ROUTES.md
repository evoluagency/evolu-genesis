# Platform UX routes

- `/` — product presentation, problem statement, workflow and architecture.
- `/demo/` — Platform operational synthetic scenario.
- `/demo/?mode=guided` — the same synthetic scenario with the guided walkthrough started automatically.
- `/preview/` — contract-first UX previews used during progressive migration.

The presentation and operational surfaces intentionally use different density and information hierarchy.

The current GitHub Pages URL contains the legacy repository name. Route URLs are technical deployment details and do not define product nomenclature.
